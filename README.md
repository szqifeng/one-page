# 季度双周滚动规划看板

一个面向混合型团队的一页纸规划工具：用季度视角管理总投入，用双周视角管理近期承诺，并持续观察每个人的 DPO 与日常需求容量。当前工程由参考包中的单文件 HTML 版本迁移为 Umi Max + React 应用。

## 当前能力

- 保留参考包的 7 轮双周规划、交付内容/人天分列和明细表
- DPO / 日常需求分类与筛选
- 迭代投入、季度投入、单人投入和事项投入分析
- 每轮人员容量、每个人独立的 DPO / 日常比例预算和超载预警
- 新增、编辑、删除事项以及跨双周的交付与人天分配
- 人员类型维护：开发、运营、产品，可继续新增和停用
- 人员维护：账号、类型、状态、容量、日常占比和权限角色
- 权限角色维护：管理员、规划负责人、普通成员和自定义角色
- 权限实际约束规划编辑、本人事项、人员、类型和角色维护操作
- 本地身份切换，用于验证不同角色的操作边界
- 浏览器本地持久化，刷新后保留修改

## 本地运行

```bash
pnpm install
pnpm dev
```

默认访问 `http://localhost:8000`。

## 验证

```bash
pnpm test
pnpm build
```

当前版本是本地多身份演示 MVP，身份切换仅用于验证权限。接入服务端时应由登录态提供当前用户，并在服务端再次校验权限；前端按钮控制不能替代服务端鉴权。
